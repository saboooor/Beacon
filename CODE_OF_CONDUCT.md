# Code of Conduct

## Our pledge

We want this project to be a welcoming, respectful place for everyone. Harassment, personal attacks,
discrimination, and deliberately disruptive behavior are not welcome.

## Expected behavior

- Be constructive and assume good intent.
- Respect different experience levels and viewpoints.
- Keep security reports and other sensitive details out of public discussions.

## Enforcement

The project maintainer may remove comments, close discussions, or block contributors whose behavior
does not meet this standard. To report a Code of Conduct concern, contact
[@saboooor](https://github.com/saboooor) privately through GitHub.
